# Lesson Lab Backups

Lesson Lab Backups is a privately operated tool for backing up
a community Discord teaching-record database to the operator’s
Google Drive.

The working database is stored on the operator’s Linux server.
Dated backup copies support recovery and transfer to a replacement
host. This website does not provide access to those backups.

## Privacy policy

Updated: 9 November 2026

### Information handled
Database backups may contain Discord user IDs, character names,
lessons, sessions, enrollments, completion records and approval
history.

The tool uses Google authorization to create and manage its own
backup files and folders. It requests the limited drive.file
permission, rather than access to every file in the account.

### Purpose and access
Information is used for operating the community’s teaching
records, restoring lost data and transferring hosting when needed.
Backup files are not intentionally published or sold.

Google Drive stores the uploaded backups. Hosting may be
transferred to an authorized successor responsible for the service.

### Credentials and retention
Google authorization credentials are stored locally on the server,
separately from database backups. They are not published on this site.

Backup copies remain until removed by the operator. Removing a
record from the working database does not immediately remove it
from older backups.

### Account controls
The Google account owner can revoke the tool’s authorization
through Google Account settings. Existing backup files can be
deleted through Google Drive.

### This website
This site contains information only. It has no login or forms,
and the project adds no analytics. GitHub Pages may process
technical access information under GitHub’s privacy policy.
